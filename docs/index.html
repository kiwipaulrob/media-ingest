media-ingest

A tested, modular media ingest pipeline for a Jellyfin homelab — with a Hermes agent plugin, a metadata provider chain, and 468 tests. Every safety rule is paired with the incident that produced it.

What it does

Ingesting media means answering four questions safely: what finished downloading, does the library already have it, replace or add, and did the write actually land and is it playable. The hard part is that each step is destructive if it guesses — a half-copied file, a mis-matched title, or a wrong synopsis written over a good one is silent damage that surfaces days later.

So the design rule is simple: read-only stages do all the thinking, and mutating stages only execute explicit ids.

The pipeline

Prowlarr ──▶ source plan ──▶ shortlist ──┐
qBittorrent ─▶ scan ──▶ plan ──▶ ids ─────┼──▶ apply (replace existing file)
library dump ─────────────────────────────┘    ingest_new (place new file)
                                              verify (4-field gate)
StageMutatingContract
scannocompleted downloads, probed for real resolution and codec
plannoREPLACE candidates as numbered ids, plus rows for a human
applyyesexplicit ids only — there is no "all" switch, by design
placeyesadds a file that has no row yet, with five gates
verifynoTmdb / Imdb / image / overview gate per item

Why it exists

Ad-hoc ingest scripts written per task kept failing in the same ways. Two examples from the README, both now pinned by tests:

  • Advertised seeders lie. Postings showing 63 and 95 seeds both delivered zero bytes and zero peers — so seed counts are a floor for offering a pick, never evidence it is alive.
  • TMDB episode numbers do not match a hand-built library. Resolving by number wrote Tom Petty's synopsis onto a John Lennon episode, and Def Leppard's onto a Sex Pistols one. Episodes are now resolved by name.

Install

git clone https://github.com/kiwipaulrob/media-ingest.git
cd media-ingest
python3 -m pytest tests/ -q     # 468 tests, standard library only

The Hermes plugin lives in vendor/plugins/media-ingest/ and exposes media_scan, media_plan, media_apply, media_verify, media_source_plan and media_source_queue as agent tools.
